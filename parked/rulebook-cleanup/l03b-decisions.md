Covering question for K2, K6, K7: does review.md:14 "a broken rule in AGENTS.md" cover the AGENTS.md "Engineering rules" summary bullets?
- AGENTS.md:175-176: "These points summarise the topic files and apply to every change. Where this summary and a topic file differ, the topic file wins."
- Decision: YES. The bullets are lines in AGENTS.md and "apply to every change"; the "topic file wins" sentence settles differing content only. Here the content does not differ (engineering.md ST-ENG-01/05/06 say the same), and neither engineering.md nor any other topic file states a severity (grep for "should fix|blocking" in engineering.md, testing.md, documentation.md: no hit; only review.md and security.md). So the severity comes only from review.md:14, and it names AGENTS.md. A fault in a numbered ST-ENG rule alone (not repeated in AGENTS.md) is should fix under review.md:15 ("A real defect or rule break with limited impact"); the same fault, where an AGENTS.md bullet repeats the rule, is blocking. The ST-ENG-05 and ST-ENG-01/06/16-18 faults are such repeated rules (AGENTS.md:178-184).
- Caveat: if the owner reads "in AGENTS.md" as "numbered ST-AG rules only", K6 and K7 become drift and K2 stays a conflict. The text as written does not say that.
