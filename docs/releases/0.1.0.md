# Release notes: Stratum 0.1.0

**Released** on Maven Central on 2026-11-11, from the tag
[`v0.1.0`](https://github.com/exepex/stratum/tree/v0.1.0). It is Stratum's first release.

[← Documentation home](../README.md) · [Versioning and upgrades](../guides/upgrading.md) ·
[ADR 0020: Version numbers and releases](../adr/0020-version-numbers-and-releases.md)

These notes describe the tag. Pages on `main` may describe changes made after it; those changes come in 0.2.0.

## What is published

24 artifacts, each with its sources and Javadoc jars, signed.

### Build and platform

| Artifact | What it is |
| --- | --- |
| `stratum` | The root POM: the versions Stratum chooses, inherited by the parents below |
| `stratum-parent` | The parent POM for any kind of application ([Parent POMs and BOM](../modules/parent-and-bom.md)) |
| `stratum-microservice-parent` | The parent POM of a REST microservice, which brings its bundle and the test libraries |
| `stratum-bom` | The bill of materials, for a service that keeps its own parent |
| `stratum-build-parent` | The build checks and `stratum-bom`, shared by services and Stratum's own modules |
| `stratum-library-parent` | The parent of Stratum's own libraries and starters |
| `stratum-build-rules` | The Checkstyle, PMD and Maven Enforcer rules that the build checks load |

### Libraries

`stratum-core`, `stratum-redaction`, `stratum-web`, `stratum-http-client` and `stratum-test`. The starters
bring them; a service adds only `stratum-test`, in test scope, when it does not use
`stratum-microservice-parent` ([Testing](../modules/test.md)).

### Starters

| Starter | Status in 0.1.0 |
| --- | --- |
| [`stratum-starter-webmvc`](../../starters/stratum-starter-webmvc/README.md), [`stratum-starter-webflux`](../../starters/stratum-starter-webflux/README.md) | Built: error responses, request fields in logs, the correlation ID, the request log, timeouts and the body size limit |
| [`stratum-starter-cache`](../modules/cache.md) | Built: caching switched on, with safe defaults for Spring Boot's Redis cache |
| [`stratum-starter-logging`](../../starters/stratum-starter-logging/README.md) | Partly built: JSON logs with the service's name and environment, redaction, and named workflows |
| [`stratum-starter-observability`](../../starters/stratum-starter-observability/README.md) | Partly built: metrics, traces and health sent over OTLP, with safe defaults |
| [`stratum-starter-http-client`](../modules/http-client.md) | Partly built: clients of other services as `@StratumClient` interfaces, with their own timeouts, pool, retries, circuit breaker and trace headers |
| [`stratum-starter-oauth2-client`](../modules/oauth2-client.md) | Spring Security's OAuth2 client, so an HTTP client can send the service's own token |

### Bundles

`stratum-starter-microservice`, `stratum-starter-reactive-microservice`, `stratum-starter-web-ui`,
`stratum-starter-batch` and `stratum-starter-cli`: one dependency per kind of application
([Bundle starters](../modules/bundles.md)).

[GHSA-ccrj-gw8r-854m](https://osv.dev/GHSA-ccrj-gw8r-854m) (Medium). Set 1.67.0 in your service as
[Open advisories](../guides/upgrading.md#open-advisories) shows.

## Breaking changes

None: this is the first release. From 0.1.0 on, each breaking change has a migration note in the release notes of
the version that ships it.

## For snapshot users

`main` now builds `0.2.0-SNAPSHOT`. `0.1.0-SNAPSHOT` no longer changes, and the snapshot repository deletes it after
90 days: move to the released `0.1.0`, or to `0.2.0-SNAPSHOT` to follow `main`
([Using a snapshot](../getting-started/installation.md#using-a-snapshot)).
